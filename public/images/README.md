# 📁 Dossier Images

## 🎨 Images à ajouter ici

### Logo principal
- **Nom du fichier** : `logo.png`
- **Taille recommandée** : 200x200px minimum
- **Format** : PNG avec fond transparent
- **Utilisation** : Navbar, Footer, SEO

### Favicon
- **Nom du fichier** : `favicon.ico`
- **Taille** : 32x32px
- **Format** : ICO
- **Utilisation** : Icône du navigateur

### Icônes mobile (PWA)
- **Nom du fichier** : `icon-192.png`
- **Taille** : 192x192px
- **Format** : PNG

- **Nom du fichier** : `icon-512.png`
- **Taille** : 512x512px
- **Format** : PNG

### Image Open Graph (Réseaux sociaux)
- **Nom du fichier** : `og-image.jpg`
- **Taille** : 1200x630px
- **Format** : JPG
- **Utilisation** : Aperçu sur Facebook, LinkedIn, Twitter

---

## 📝 Comment ajouter les images

### Méthode 1 : Glisser-déposer
1. Ouvrir le dossier `public/images/` dans l'explorateur de fichiers
2. Glisser-déposer vos images ici

### Méthode 2 : Ligne de commande
```bash
# Depuis la racine du projet
cp /chemin/vers/votre/logo.png public/images/logo.png
```

## 🎨 Créer les images manquantes

Si vous n'avez pas toutes les images, vous pouvez :

1. **Utiliser Canva** (gratuit)
   - https://www.canva.com
   - Templates disponibles pour logos, icônes, etc.

2. **Convertir votre logo**
   - PNG → ICO : https://convertio.co/fr/png-ico/
   - Redimensionner : https://www.iloveimg.com/fr/redimensionner-image

3. **Générer un favicon**
   - https://favicon.io/
   - Upload votre logo et téléchargez le favicon
